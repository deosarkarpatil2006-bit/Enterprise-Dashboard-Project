# Northstar Enterprise Dashboard

Accessible multi-section enterprise dashboard demo built with semantic HTML5, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Included
- Semantic landmarks and heading hierarchy
- Skip link, keyboard focus styling, labels, fieldset/legend, live status messages
- Responsive sidebar and KPI cards
- Searchable project table
- Native accessible modal dialog with required-field validation
- Reduced-motion support

## Validate
Upload `index.html` to https://validator.w3.org/ and fix any reported issues before submission.

## Publish to GitHub
1. Create a new repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Enable GitHub Pages under repository Settings → Pages if you need a live demo.
